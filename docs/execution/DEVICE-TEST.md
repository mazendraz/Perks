# L08 — سجل اختبار الأجهزة الحقيقية

الحالة: **BLOCKED_OWNER / NOT_RUN على الهاردوير الحقيقي**. فحوص Chromium وWebKit المحلية دليل آلي منفصل،ولا تساوي اختبار آيفون أوأندرويد فعلي. لا يوجد رابط عام مفتوح حاليًا،ولم يُنشر staging. المطلوب من المالك: توفير الأجهزة والستيكر NFC،وتحديد المضيف والدومين،واعتماد فتح تجربة صناعية فقط.

## تجهيز تجربة الموبايل

```powershell
npm run tunnel:setup
npm run dev:tunnel
```

الأول ينزل cloudflared الرسمي2026.10.7 ويطابقSHA-256،ويشغّل`--version` فقط. الثاني يجهز قاعدة جديدة باسم`nuqta_tunnel_<وقت>_<عشوائي>` وحسابات وملفات صناعية خاصة،ولا يفتح رابطًا. لا تُستخدم قاعدةمازن أوأي قاعدةموجودة. أماكن حسابات المنصة والمالك والكاشير تظهر كمسار ملف`logins.txt` داخل`.local/tunnel-demo/<التجربة>`؛الأسرار لا تُطبع فيstdout ولا تدخلGit. العميل يبدأ منQR بالاسم والرقم والشروط،بلا إيميل أوباسورد.

بعد اعتماد المالك فتح الرابط،أوقف أمر`npm run dev` الذي يشغل5173 ثم شغّل:

```powershell
npm run dev:tunnel -- --publish-synthetic
```

الأمر يرفض الاستيلاء علىport مشغولة،وينشئ تجربة جديدة دائمًا. افتح رابطHTTPS الذي يطبعه من الموبايل. حسابات التجربة الجديدة منملفها الخاص؛حسابمازن الموجود على4180 لم يتغير. استخدم أسماء وأرقامًا صناعية فقط. Ctrl+C يوقف عملياته والرابط. البيانات الخاصة بالتجربة تظل محليًا للمراجعة ولا تُنقل إلى قاعدةمازن؛الرابط التالي لهhostname جديد،فتسجيل الجهاز يبدأ من جديد. لا تستورد بيانات محلات حقيقية إلىهذه القاعدة.

واجهةVite تقبلhostname الرابط المحدد فقط،وتحجب`.env` و`.local` ومجلداتالمفاتيح والملفاتخارججذورالواجهة؛اختبارcanary يراجع ذلك. الدخولpassword وcookiesSecure/HttpOnly/Strict،وقناةlocal/mail وOTP مقفولتان. ملفاتالحفظ منفصلة وMAIL_TRANSPORT=file فقط؛لاSMTP حقيقي. Origin/CSRF وRLS وidempotency وحدودالتسجيل لم تُعطّل. كلزوارالنفق يتشاركونIP loopback عندAPI لأننا لا نثق فيheaders الزائر؛حدودالتسجيل قدتظهر بعد5تسجيلات/ساعة في التجربةالواحدة.

**حدود النفق:** [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) لا تدعمSSE،ولها200طلب جارٍ بلاضمانuptime. لذلكالمساراتالحية ترجع503 منproxyالتجريبي لتشغيلpolling الموجودة كل3ثوانٍ. ظهورالختم تحتثانية يُختبرعلىstaging/production معSSE،ولا يُقاسعلىهذاالنفق. [الإصداروالبصماتالرسمية](https://github.com/cloudflare/cloudflared/releases/tag/2026.10.7). لا يلزمحسابCloudflare أوشراءدومين للتجربةالمؤقتة.

## ما تحقق محليًا

`npm run test:tunnel`: قاعدةجديدةفقط،private files/pepper،Vite فعلي معReact وHost allowlist،منعprivate canary والمساراتالمشفرة،إغلاقSSE الخاصبالنفق،Securepassword وOrigin/CSRF،وقاعدةبمحلينصناعيين وQR فعالة. التقرير`tunnel.json` يثبت`externalTunnelOpened:false`. Chromium/WebKit والـPWA والكاميراالصناعية في`mobile.json`،والحركة في`animation/`،كلها أدلةآلية وليستسجلالجهازالحقيقي.

إعدادstaging وطريقةعزلها وحدودالقبول في[STAGING](../../deploy/STAGING.md).
